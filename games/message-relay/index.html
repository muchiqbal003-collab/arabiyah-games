شاشة العرض

Untuk TV/proyektor
(hanya skor + timer)

🎯 Cara Setup:
1. Hubungkan laptop ke TV dengan HDMI
2. Di Windows: tekan Win + P → pilih Extend
3. Buka file ini 2x di browser
4. Window 1: klik 🖥️ الشاشة الحاكمة, taruh di laptop
5. Window 2: drag ke TV, klik 📺 شاشة العرض
6. Tekan F11 di kedua window untuk fullscreen
✨ Selesai! Kalimat hanya tampil di laptop, TV hanya tampil skor.
